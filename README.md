# 红外可见光无人机目标检测数据集

## 
红外可见光双模无人机目标检测数据集UAVDataset，总计11668张640×640像素图像，划分训练/验证/测试子集，适配全天候无人机巡检目标检测任务。数据集融合可见光细节信息与红外热辐射特征，采集于交通、边境、灾害、生态等多场景，覆盖昼夜、雾雨、植被遮挡等恶劣工况，可训练鲁棒性强的双模检测模型，用于交通动态管控、边境安防、应急救援、生态监测，有效减少复杂环境目标漏检误判，为行业风险预警与现场处置提供数据支撑。
